# TestRecettes

Planificateur de menus normands – une petite application web simple qui permet de composer les repas du midi et du soir pour chaque jour de la semaine.

## Site en ligne
👉 https://jeanb1970.github.io/TestRecettes/

## Fonctionnalités
- Saisie libre des plats (entrée, plat principal, légumes, féculents, dessert)
- Nombre de convives (1‑6) obligatoire
- Validation des champs obligatoires
- Récapitulatif trié du lundi au dimanche
- Persistance locale avec `localStorage`
- Design inspiré des cuisines familiales normandes (couleurs crème, vert sauge, touches de rouge brique)

## Installation locale
1. Clone du dépôt
2. Ouvrez `index.html` dans votre navigateur (aucune dépendance, pas besoin de serveur).

## Développement
Le code source se compose de :
- `index.html`
- `styles.css`
- `app.js` (généré à partir de `app.ts`)
- Images dans le dossier `assets/`
